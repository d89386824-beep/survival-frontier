# SURVIVAL: FRONTIER — стартовый игровой проект

Это исходный проект-прототип на Godot 4. Он создаёт тестовую 3D-площадку, персонажа от первого лица, сбор дерева/камня, простейший инвентарь, показатели выживания и базовую ENet-точку входа для сервера.

## Требования
- Godot Engine 4.3 или новее.
- Для Windows: экспортные шаблоны Godot и Windows export preset.
- Для Android: Android SDK/JDK и Android export templates, настроенные в Godot.

## Запуск
1. Распакуйте архив.
2. Откройте `project.godot` в Godot 4.
3. Нажмите Play (F6/F5).
4. Управление: WASD, Shift, Space, мышь.
5. Наведитесь на дерево/камень и нажмите E для добычи.
6. F1 запускает ENet-сервер на порту 27015; F2 подключает клиента к localhost.

## Важно о мультиплеере
Сетевой слой здесь — начальная транспортная основа, а не законченный онлайн-мультиплеер. Сейчас не реализованы авторитетная серверная симуляция мира, репликация игроков и объектов, сохранение мира, античит, матчмейкинг и мобильный интерфейс. Не открывайте этот прототип в публичный интернет как готовый сервер.
